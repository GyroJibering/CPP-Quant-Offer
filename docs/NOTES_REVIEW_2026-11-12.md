## 技术检查与修改

- 区分目标的半正定 Hessian 与 KKT 分块矩阵的不定性；核对示例的 1/2 系数、预算等式、0.4 上界、非负上界乘子与互补条件。上限 0.6 时原等式解可行，不继续假定该上界活跃。
- 求解示例检查相对残差、奇异矩阵和维度错误，拒绝非有限输入。小型稠密消元没有实现通用 QP、内点法、稀疏分解、条件数估计或生产精度控制，不把单个阈值描述为通用数值保证。
- 对照 MOSEK 官方文档，区分 response、termination、problem status、solution status 和解类型；保留 Unknown、不可靠证书、浮点容差和业务复核的限制。公开资料不用于断言特定 BarraOpt 版本的内部调用链。
- C++ 示例中的被借用对象覆盖视图使用期；智能指针引用计数不被描述为业务对象线程安全；std::move 不被描述为必然移动或零拷贝。
- 普通 price 只写一次，通过对应 release/acquire 发布；重复复用槽位另需反向同步。relaxed 计数不承担发布，消费者结果在 join 后读取。测试不依赖调度顺序，不包含故意的数据竞争。
- 区分缓存一致性与语言层同步、真共享与伪共享、地址对齐与缓存驻留；不承诺 SBO、无锁或更弱内存序必然提速。
- 对照 Proxy 仓库的迁移说明，注明 Microsoft 旧仓库归档及 ngcpp 维护地址；不混用版本，也不把教学视图当作该库实现。
- 原 MSCI factsheet URL 会重定向到通用页面，改用可访问的官方 Barra Optimizer on FactSet 产品资料，明确它只能支持产品能力层面的描述。
